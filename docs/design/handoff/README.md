# Handoff: карточка «Лот дня» для Telegram-канала (тёмный шаблон)

## Overview
Шаблон картинки 1080×1080 для постов о лотах торгов (машино-места, квартиры). Бот генерирует PNG из шаблона, подставляя данные лота. Карточка одной фразой отвечает «почему это интересно» (крупная цифра), детали — в тексте поста.

Контекстные элементы подставляются автоматически:
- **иллюстрация** по типу объекта (`type`);
- **карта Москвы** с подсветкой района лота и его округа (`district`).

## About the Design Files
`LotCardDark.dc.html` — **дизайн-референс в HTML**, не продакшен-код. Задача — воссоздать шаблон в среде бота. Рекомендуемый путь: обычная HTML-страница (или React/Vue-компонент, SSR) + headless-браузер (Playwright/Puppeteer) → скриншот элемента 1080×1080 → PNG. Альтернатива без браузера: Satori/resvg (JSX → SVG → PNG), карта — тот же SVG.

Референс открывается в браузере напрямую (рядом `support.js`), принимает данные из URL-параметров — можно сразу использовать как рендер-страницу, если устраивает.

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры финальные — воспроизводить пиксель-в-пиксель.

## Screen: карточка 1080×1080

- **Верхняя строка** (flex, space-between, center):

  - Бренд: Unbounded 700 28px, `#F6F4EE`, letter-spacing .06em. «С МОЛОТКА» (плейсхолдер — заменить на название канала).
- **Блок заголовка**: margin-top 110px, max-width 470px, flex-column.
  - Headline: Unbounded 800 132px/1, `#C8F04A`, letter-spacing −0.04em, nowrap. Пример «−44%». Рассчитан на 4–5 символов (−44%, ×2,9).
  - Subline: Onest 500 36px/1.2, `#CFE0D6`, margin-top 22px, `text-wrap:pretty`. «дешевле медианы района».
  - Дедлайн-пилюля: margin-top 32px, border 2px `#C8F04A`, текст `#C8F04A` Onest 600 28px, padding 10px 22px, radius 40px. «заявки до 9 ноября».
- **Нижний блок**: margin-top:auto, border-top 2px `#2B5A49`, padding-top 40px, grid `230px minmax(0,1fr)`, column-gap 48px, align center.
  - Иллюстрация 230×230, `object-fit:contain`, без фона. Для `parking` — `transform: scale(1.9)` (в исходнике много пустого поля); `flat` — scale 1.

    - Цена: Unbounded 700 74px/1, `#F6F4EE`, letter-spacing −0.03em, nowrap. «1,29 млн ₽».
    - Под ценой: Onest 500 30px/1.25, `#A9C4B6`, mt 14px. «медиана — 2,30 млн ₽ · 14,9 м²».
    - Адрес: Onest 700 34px/1.2, `#F6F4EE`, mt 26px, до 2 строк. «Бескудниковский бульвар, 19, стр. 1».
    - Район · округ: Onest 500 28px, `#A9C4B6`, mt 8px. «Бескудниковский район · САО» (генерируется).

### Карта — логика
Данные: `data/moscow-geo.js` → `window.MOSCOW_GEO = { districts: [{ n, o, r }], river: [] }`
- `n` — название района (OSM, без префикса «район »: «Бескудниковский район», «Хамовники», «Коммунарка»);
- `o` — округ: ЦАО, САО, СВАО, ВАО, ЮВАО, ЮАО, ЮЗАО, ЗАО, СЗАО, ЗелАО, НАО, ТАО;
- `r` — массив колец `[[lon,lat],…]`, упрощено (Douglas-Peucker ε=0.0005°), 4 знака.
- 133 района: 125 старой Москвы/Зеленограда + 8 районов ТиНАО (с 01.01.2025 поселения упразднены). Источник — OpenStreetMap (ODbL, нужна атрибуция «© OpenStreetMap» в описании канала или мелко на карточке).

Алгоритм:
1. Поиск района: нормализация `lower → ё→е → удалить «район» → оставить [a-zа-я0-9]`, сравнение по равенству.
2. Набор отображаемых районов: если округ района ∉ {ЗелАО, НАО, ТАО} — вся Москва без этих трёх; если ЗелАО — без НАО/ТАО; если НАО/ТАО — без ЗелАО.
3. Проекция: equirectangular, `x = lon·cos(55.75°)`, `y = −lat`.
4. Кадр: bbox районов **округа лота**, центр кадра = центр bbox; масштаб `s = 1 / (max(bboxW/560, bboxH/600, 0.24·cos(55.75°)/560) · 1.6)` — округ занимает ~60% кадра, соседи видны вокруг; минимальный охват ~0.24° по долготе (для маленького ЦАО).
5. Заливки (stroke `#0E3B2E` 1.3px, linejoin round — даёт «зазоры» между районами):
   - район лота `#C8F04A` (рисовать последним),
   - прочие районы того же округа `#3A7A60`,
   - остальные `#1A4F3F`.
6. Строка «район · округ»: если название оканчивается на «район» — как есть, иначе «район » + название; затем « · » + округ.

## Interactions & Behavior
Статичная картинка, без интерактива. Состояния:
- Иллюстрация не найдена → пунктирная рамка 3px `#2B6B52`, radius 24, подпись типа (Onest 600 26px `#CFE0D6`) и путь (Onest 500 20px `#7FA393`). В продакшене лучше падать с ошибкой, чем отдать карточку без картинки.
- Район не найден → карта без подсветки, вся старая Москва; в строке района — исходная строка без округа. Логировать.
- Перед скриншотом дождаться загрузки шрифтов (`document.fonts.ready`) и картинки.

## Входные данные (URL-параметры референса)
| параметр | пример |
|---|---|
| type | `parking` \| `flat` (заложены `storage`, `commercial`) |
| district | `Бескудниковский` |
| kicker | `ЛОТ ДНЯ` |
| headline | `−44%` (знак минус U+2212; `%` в URL → `%25`) |
| headlineSub | `дешевле медианы района` |
| deadline | `заявки до 9 ноября` |
| price | `1,29 млн ₽` |
| priceSub | `медиана — 2,30 млн ₽ · 14,9 м²` |
| address | `Бескудниковский бульвар, 19, стр. 1` |
| brand | `С МОЛОТКА` |
| img | переопределить путь к иллюстрации |

Форматирование: десятичная запятая, неразрывный пробел перед «₽» и «%»-знаками где нужно, минус — U+2212.

## Design Tokens
Цвета:
- `#0E3B2E` — фон (тёмный изумруд)
- `#C8F04A` — акцент (лайм): headline, кикер, пилюля, район, иллюстрации
- `#F6F4EE` — основной светлый текст
- `#CFE0D6` — subline
- `#A9C4B6` — вторичный текст
- `#2B5A49` — разделитель
- `#3A7A60` / `#1A4F3F` — округ / прочие районы
- `#2B6B52`, `#7FA393` — плейсхолдер

Шрифты (Google Fonts): **Unbounded** 700/800 — цифры, бренд; **Onest** 500/600/700 — текст.
Радиусы: пилюли 40px. Теней нет.
