# Telegram-канал «Торги Москвы»

Рабочий документ проекта: решения, стратегия, архитектура, текущее состояние и план.
**Это главный источник правды по каналу.** Продолжая работу в новом диалоге, начинайте с него
и обновляйте разделы «Состояние» и «Журнал решений» после каждого шага.

## Зачем

Канал для заработка на рекламе, построенный на данных Пульса города. Тема — городские торги
(сначала машино-места, потом нежилые помещения и прочие лоты набора № 1461): выгодные лоты,
итоги аукционов, аналитика цен.

Почему эта тема, а не общий «Пульс Москвы»:
- недвижимость и инвестиции — одна из самых дорогих тематик рекламы в Telegram;
- контент уникален и генерируется автоматически: `track-digest` находит выгодные лоты, `track-torgi` — итоги;
- рекламодатели понятны: застройщики, риелторы, банки (ипотека), юристы по торгам, сервисы ЭЦП;
- рядом есть платный продукт: бот с персональными уведомлениями по фильтру.

Минус: потолок аудитории — десятки тысяч, не сотни. Ниша берёт ценой подписчика, а не объёмом.

Запасной вариант на потом: сеть районных каналов (аварии с отключениями, открытия заведений) —
массовая аудитория, дешёвая реклама от местного бизнеса.

## Контент: рубрики

| Рубрика | Частота | Источник | Состояние |
|---|---|---|---|
| **Лот дня** — 1–2 самых выгодных лота с карточкой | будни | `digest.lot_findings` | ✅ `channel-draft` |
| **Итоги** — «старт 1,0 млн → продано за 2,9 млн» | по мере появления | `track-torgi` | ✅ `channel-draft` |
| **Неделя вперёд** — выгодные лоты с дедлайном заявок за 7 дней | понедельник | `metrics.parking_lots` | ✅ `channel-draft` |
| **Угадай цену** — опрос до торгов, ответ после итогов | 2–3 раза в неделю | лоты + `track-torgi` | ⏳ этап 2 |
| **Аналитика месяца** — медиана ₽/м² по округам, доля несостоявшихся торгов, рост цены | раз в месяц | журнал + итоги | ⏳ |
| **Ликбез** — как участвовать: ЭЦП, задаток, сроки, подводные камни | один раз, закрепить | вручную | ⏳ пишет автор |

Правила:
- 2–3 поста в будни, 0–1 в выходные. Плотность важнее количества.
- В каждом посте — одна строчка от себя (место помечено «✏️ ваш комментарий»). Это отличает канал от бота.
- Посты — факты и цифры («ниже медианы на X %»), не инвестиционный совет.
- Карточки — только по шаблону из кода, ничего не рисуется вручную. Единый стиль: тёмно-синий фон, янтарный акцент.

## Продвижение

| Этап | Когда | Что делать |
|---|---|---|
| 0. Наполнение | первые 2–3 недели | автопостинг черновиков, 30–50 постов, закреп с ликбезом, показать 10–20 знакомым. **Не продвигать.** |
| 1. Бесплатный рост | до ~1 000 | статья-исследование на vc.ru / Хабре («проанализировал N торгов…»), питч изданиям о недвижимости, взаимопиар с каналами того же размера, ключевые слова в названии, полезные лоты в чатах ЖК |
| 2. Платная закупка | охват поста ≥ 30–40 % подписчиков **и** есть рост от пересылок | тест на 3–5 каналах про недвижимость и инвестиции; считать цену подписчика и долю оставшихся через 2 недели; масштабировать только окупаемое |
| 3. Монетизация | от ~3–5 тыс. живых подписчиков | прямые размещения, рекламная монетизация Telegram, платный бот |

Метрики: охват поста к числу подписчиков (ERR), пересылки и сохранения по рубрикам, отписки после постов,
цена подписчика при закупке.

Юридически: от 10 000 подписчиков — регистрация канала в РКН (без неё рекламу размещать нельзя);
реклама маркируется (erid через ОРД).

Двигатель роста на будущее: бот «пришлю лоты по вашему фильтру» (округ, бюджет, тип). Бесплатно — при подписке
на канал (воронка), платно — мгновенные уведомления и снижения цен.

## Архитектура

Канал — отдельный пакет `parkan/channel/` в этом же репозитории. **Он только читает данные Пульса,
Пульс о канале ничего не знает.**

```
Пульс (parkan/track)                         Канал (parkan/channel)
track-sync  → state/ds1461/events-*.parquet ─┐
track-torgi → таблица итогов (CSV)          ─┼→ content.py   отбор по рубрикам, своя политика POLICY
digest.lot_findings (Finding.data)          ─┤   templates.py тексты постов (HTML) и данные карточек
metrics.parking_lots                        ─┘   cards.py     PNG-карточки (Pillow)
                                                 telegram.py  Bot API без сторонних библиотек
                                                 commands.py  channel-draft
                                                 channel_state/drafted.json — что уже уходило
```

Что общее, а что раздельное:

| Изменение в Пульсе | Влияет на канал? |
|---|---|
| Разбор наборов, парсинг torgi.mos.ru, исправления данных | да, так и задумано |
| Расчёты: медиана района, ₽/м², снижение цены | да, цифры в канале и на дашборде совпадают |
| Пороги и лимиты сводки для Trello | нет: у канала свой `POLICY` в `parkan/channel/content.py` |
| Тексты сводки для Trello | нет: свои шаблоны в `templates.py` |
| Аварии, лицензии, качество данных | нет, канал их не берёт |

Контракт с Пульсом: `Finding.data` у находок по лотам (`address, district, price, space, m2, lots, until, url`,
плюс `median, discount` / `m2_p05` / `old_price, drop` в зависимости от вида), строки таблицы итогов
(`torgi.FIELDS`) и `metrics.parking_lots(...)["lots"]`. Контракт защищают тесты `tests/test_channel.py`:
переименовали поле в Пульсе — упадут они, а не канал в проде.

Какие данные канал берёт:
- журнал № 1461: лоты в продаже (адрес, район, цена, площадь, ₽/м², сроки заявок, ссылка), медианы по районам, история цены;
- таблица итогов `track-torgi`: статус, итоговая цена, отношение к старту, ₽/м², метро, ссылки на лот и протокол.

Не берёт: лицензии (№ 586), аварии и земляные работы (№ 62461, № 62501). Фото лотов Пульс не хранит
(`drop=("Photo",)`), карточки обходятся без них.

## Эксплуатация

Установка: `pip install -e '.[channel]'` (Pillow для карточек). Нужен шрифт с кириллицей — по умолчанию DejaVu Sans,
иначе пути в `PARKAN_FONT` и `PARKAN_FONT_BOLD`. Без Pillow черновики уходят текстом.

Настройка Telegram (один раз):
1. Создать бота у @BotFather → токен.
2. Создать закрытый канал-«кухню» для черновиков, добавить бота администратором.
3. Создать публичный канал, автор — администратор.
4. Узнать id кухни (например, переслать из неё сообщение в @userinfobot; у каналов id вида `-100…`).

Переменные окружения (хранить в `.env`, он в `.gitignore`):

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `TELEGRAM_DRAFT_CHAT` | id кухни |
| `PARKAN_CHANNEL_NAME` | подпись на карточках, по умолчанию «Торги Москвы» |
| `PARKAN_CHANNEL_STATE` | папка состояния канала, по умолчанию `channel_state` |
| `PARKAN_STATE` | журнал Пульса, по умолчанию `state` |

Ежедневный запуск — сразу после Пульса:

```cron
0 6 * * *  cd /srv/parking && .venv/bin/parkan track-sync && \
           .venv/bin/parkan track-torgi --results results/torgi-mashinomesta.csv && \
           .venv/bin/parkan channel-draft --results results/torgi-mashinomesta.csv --send
```

Без `--send` команда только складывает тексты и карточки в `channel_out/<дата>/` (просмотр). С `--send` отправляет
их в кухню и запоминает в `channel_state/drafted.json`, чтобы тот же лот или итог не пришёл повторно.
Рубрики можно задать явно: `--rubrics lot,result,week`. Для проверки на прошлой дате — `--today 2026-10-06`.

Работа автора каждый день (15–20 минут): открыть кухню, выбрать посты, заменить «✏️ ваш комментарий» своей фразой,
скопировать в основной канал и поставить в отложенную публикацию Telegram.

Папку `channel_state/` хранить так же, как журнал Пульса (не удалять между запусками).
