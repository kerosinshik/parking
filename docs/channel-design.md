# «Попутный Метр»: типы сообщений и шаблоны

Дополнение к [channel.md](channel.md). Здесь окончательный список сообщений канала. Для каждого типа:
когда оно выходит, откуда берутся данные, точный шаблон текста и какие поля нужны на картинке.

**Статус (12.10.2026):** список типов и тексты ждут подтверждения автора. Дизайн выбран: макет
«Лот дня» из Claude Design (тёмный изумруд `#0E3B2E` + лайм `#C8F04A`, Unbounded + Onest, карта районов,
иллюстрация по типу объекта) — `docs/design/handoff/`. Код: `parkan/channel/html_cards.py`
(HTML → PNG через headless Chromium), в `channel-draft` ещё не подключён.

## Название

**«Попутный Метр»** (выбрано автором 12.10.2026). Игра слов: «попутно» — находки, которые попадаются
по дороге, и «метр» — квадратный метр, то есть недвижимость в целом. Название подходит и для
машино-мест, и для расширения на все лоты № 1461.

Слов «торги» и «Москва» в названии нет, поэтому их нужно добавить в описание канала для поиска Telegram.
Пример описания: «Торги Москвы: машино-места и недвижимость ниже рынка, итоги аукционов».

## Что показала проверка на живых данных (12.10.2026)

- В продаже 2 461 машино-место. Новых лотов на 25 % и больше дешевле района выходит около одного в день,
  обычно пачкой в одном доме.
- 54 дома продают сразу 10 и больше мест, рекорд — 189 мест в одном доме.
- Из 81 проданного за 10 дней лота **половина ушла по стартовой цене** (медиана роста — ×1,0), рекорд — ×3,2.
  Это главный сюжет канала: на многие торги никто не приходит.
- Адреса длинные, до 140 знаков в исходном виде. На картинке — сокращённый адрес до ~45 знаков.

## Объекты

Машино-места и квартиры, только Москва и Новая Москва (Подмосковье не берём). Машино-места сравниваются
по цене лота с медианой района, квартиры — по цене за м². В районе меньше 5 лотов того же типа —
сравнение с округом («дешевле округа»). У каждого поста второй хэштег: #машиноместа или #квартиры.
Иллюстрация на карточке — по типу (`parking.png`, `flat.png`).

Лимиты на день: не больше 2 «лотов дня», 2 снижений, 2 итогов «дороже», 1 «без борьбы», 1 «целого дома»; в пределах лимита машино-места и квартиры чередуются. Если новых выгодных лотов меньше нормы, «Лот дня» добирает лучшими из лотов в продаже, которые ещё не выходили. «Две недели вперёд», «Заявки заканчиваются», «Срез торгов» и «Итоги недели» — отдельный пост на каждый тип (подборка — от 3 лотов, «Заявки заканчиваются» — от 2). Пороги — `POLICY` в `parkan/channel/content.py`.

## Тексты

Тексты пишет Claude по навыку `.claude/skills/channel-copy/SKILL.md` — там голос, форма, правила по рубрикам
и примеры. Коротко: живая заметка на 300–700 знаков, заход жирным, ссылка на лот внутри фразы;
без эмодзи, хэштегов и столбиков реквизитов (решение 12.10.2026). Цифры и ссылки — только из фактов поста,
это проверяет `parkan channel-lint`. Шаблонные тексты в `templates.py` — только запасной вариант.

## Бриф для дизайна (Claude Design)

Нужны шаблоны картинок для типов 1–7 и 10–11, в одном стиле.

**Формат.**
- PNG 1080×1080. В ленте Telegram картинка видна шириной ~360 px, то есть в 3 раза меньше.
- Главное число — от ~200 px, остальной текст — не меньше 34 px.
- Текст поста идёт отдельно, под картинкой, поэтому на картинке — только главное.

**Общие элементы:**
- метка рубрики («ЛОТ ДНЯ», «ИТОГИ ТОРГОВ» …);
- название канала «Попутный Метр»;
- одно главное число;
- 2–3 строки пояснения;
- плашка со сроком или датой;
- по желанию — мини-схема Москвы (кольца МКАД, ТТК, Садового) с точкой места: координаты есть у каждого лота.

**Требования к вёрстке.** Код подставляет данные в макет, поэтому вёрстка должна выдерживать:
- длинный адрес: до ~45 знаков, перенос на 2 строки;
- длинное число: «−73 %», «×3,2», «12,50 млн ₽», «189 мест»;
- пустое поле: например, нет метро или площади.

Что прислать для реализации:
- макеты, по одному на тип;
- цвета (hex) и шрифты — лучше свободные с кириллицей и знаком ₽, например Unbounded, Onest, Manrope, Inter;
- для мини-схемы — как она выглядит.

Ранние прототипы трёх направлений (`docs/design/`) можно использовать как отправную точку или игнорировать.
