# Журнал учёта динамических данных

Ветка хранит только журнал изменений наборов data.mos.ru, код — в ветке `main`.
`state/ds<ID>/events-<время>.parquet` — события одного запуска `parkan track-sync`
(added / changed / removed). Файлы только добавляются.

Источник: Портал открытых данных Правительства Москвы (data.mos.ru).
