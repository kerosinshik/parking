# Заметки для Claude Code

`parkan` — аналитика парковок Москвы и «Пульс города» (учёт живых наборов портала открытых данных:
лицензии на алкоголь, торги городским имуществом, аварийные и земляные работы). Подробности — README.md.

## Telegram-канал

Канал о городских торгах на данных Пульса: код в `parkan/channel/`, всё остальное — в **docs/channel.md**
(стратегия, рубрики, продвижение, архитектура, эксплуатация, состояние, журнал решений).

Когда работа касается канала:
1. Сначала прочитать `docs/channel.md`.
2. Канал только читает Пульс; Пульс не должен зависеть от `parkan/channel`. Пороги канала — `POLICY`
   в `parkan/channel/content.py`, не трогать ради канала пороги сводки Trello в `parkan/track/digest.py`.
3. После изменений обновить в `docs/channel.md` разделы «Состояние» и «Журнал решений» (с датой).
4. Рилсы для Instagram (кадры, описание, комментарий, учёт ссылок) — по навыку `.claude/skills/reels`.
5. Тексты постов пишутся по навыку `.claude/skills/channel-copy` (факты — `channel_out/<дата>/*.facts.json`,
   проверка — `parkan channel-lint`, отправка — `parkan channel-send`).

## Соглашения

- Документация, комментарии, сообщения CLI и коммитов — на русском.
- Единственная обязательная зависимость — DuckDB; остальное — необязательные extras (`[channel]` — Pillow).
- Тесты: `pip install -e '.[dev,channel]' && pytest`. Сетевые вызовы в тестах подменяются транспортом.
